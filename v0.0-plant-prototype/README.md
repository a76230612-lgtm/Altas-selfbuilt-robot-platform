# v0.0 Plant Care Automation Prototype
## Project Overview
This is my earliest pre-research prototype, built before the Atlas robot series.
I designed an automatic plant care system to monitor soil moisture and control water supply automatically.

## Core Functions
1. Read soil moisture data via sensors
2. Simple logic to trigger water pump when soil is dry
3. Basic closed-loop control practice

## What I Learned
- Basic embedded programming
- Sensor wiring and circuit assembly
- How to test and adjust control parameters

## Limitations of this prototype
- Simple function, no data recording
- Poor stability, not suitable for long-time running
- Only for technical verification

## Main Files
- src/: Source code of the control program
- docs/: BOM list, wiring diagram
- test/: Simple sensor test records
- media/: Photos of the prototype
