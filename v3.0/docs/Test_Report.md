## 建议复测流程

1. 复制版本文件夹，不在唯一原件上测试。
2. 按 README 的依赖与端口设置启动。
3. 一次只测一个功能并保留完整终端输出。
4. 把日期、输入、预期、实际、PASS/FAIL 写入新测试记录。
5. 涉及舵机时先低负载、保守角度、短时间运行，异常立即断电。
