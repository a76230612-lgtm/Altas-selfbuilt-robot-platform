# Atlas 6.0

Atlas 6.0是一套基于ESP32与ROS2的模块化移动机器人学习项目。

## 当前状态

- 当前阶段：Stage 2 — 建立工程骨架。
- Stage 1软件环境：由Eric确认已经完成。
- 本阶段禁止连接底盘电机或编写完整运动代码。
- 当前ESP32主程序仅为安全占位程序，不分配电机GPIO，不产生运动输出。

## 目录说明

- `docs/`：产品、架构、硬件、GPIO、安全、协议、软件和验收标准。
- `esp32_firmware/`：ESP32正式固件与单部件测试程序，和ROS2分开管理。
- `ros2_ws/`：ROS2 Jazzy工作区；Stage 2只保留包目录，不创建功能节点。
- `tools/`：串口监视、标定和数据记录辅助工具；Stage 2不实现。
- `tests/`：软件测试和测试说明。
- `test_data/`：Eric实体测试产生的CSV、TXT和日志数据。
- `archive/`：只读归档入口；不得修改Atlas 5.0稳定版本。

## 已确认的5.0硬件基线

- Pan水平舵机：GPIO 18，禁止擅改。
- Tilt垂直舵机：GPIO 19，禁止擅改。
- 其他GPIO、ESP32准确型号、OLED型号和串口协议：必须根据5.0最终文件或实物确认，不得猜测。
