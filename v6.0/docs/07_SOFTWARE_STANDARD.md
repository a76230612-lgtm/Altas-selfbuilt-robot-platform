# 07 — Atlas 6.0软件标准

## 通用规则

- Python和ROS2使用清晰的`snake_case`命名。
- ESP32常量使用大写下划线，函数名称表达实际动作。
- 配置参数集中管理，不在多个文件重复写死。
- 不静默忽略异常；错误必须记录并进入安全状态。
- 不使用API Key、OpenAI API或云端AI依赖。

## ESP32规则

1. 上电立即初始化为停车和驱动禁用。
2. 不使用长时间阻塞`delay()`实现控制流程。
3. 使用`millis()`完成定时、超时和状态更新。
4. STOP、DISARM、通信超时和非法命令路径必须可测试。
5. GPIO只能来自已确认并锁定的GPIO表。
6. 完整固件必须能够独立编译，修改时输出完整INO文件。

## ROS2规则

1. 包放在`ros2_ws/src`，构建输出不得进入Git。
2. 节点名称、Topic名称和Message类型必须记录。
3. 安全节点位于用户命令和电机执行之间。
4. 节点退出和串口异常必须有停车处理。
5. 修改后至少运行`colcon build`和相关节点测试。

## 日志与数据

- 实体测试数据写入`test_data/`，不得虚构。
- 错误记录包含日期、完整命令、完整报错和实际现象。
- 每次只修改一个主要变量，并记录修改前后结果。
