# 02 — Atlas 6.0系统架构## 计算环境```textWindows├── Cursor / ChatGPT / Git / Arduino IDE└── WSL2    └── Ubuntu 24.04        └── ROS2 Jazzy```## 目标运行链路```text用户或行为命令→ ROS2行为节点→ ROS2安全节点→ ROS2串口桥→ USB串口→ ESP32实时固件→ TB6612FNG电机驱动→ 左右电机```## 反馈链路```text编码器 / US-100 / ESP32状态→ ESP32串口数据→ ROS2串口桥→ ROS2 Topic→ 里程、安全和行为节点```## 固定职责- ROS2：高层组织、行为、安全决策、数据发布与记录。- ESP32：实时GPIO、PWM、编码器、传感器读取、超时停车和底层执行。- `atlas_safety`：检查ARM、障碍、传感器、通信和命令时效，拥有最终否决权。- Atlas 5.0头部：在后期恢复状态显示和身体表达，不参与Stage 2运动控制。- Codex：项目外部开发辅助工具，不属于机器人运行时。## 计划中的ROS2包- `atlas_interfaces`：以后放自定义Message或Service。- `atlas_bridge`：ROS2与ESP32串口桥。- `atlas_safety`：运动命令安全审查。- `atlas_odometry`：编码器与里程数据。- `atlas_behavior`：行为状态和半自主避障。- `atlas_bringup`：统一启动配置。Stage 2只建立目录，不创建节点或依赖。
