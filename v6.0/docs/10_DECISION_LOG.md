# 10 — Atlas 6.0设计决策记录

## D-001：采用两轮差速底盘

- 状态：计划已确认，具体硬件待确认。
- 原因：结构清晰、重量相对低，适合学习基础移动、编码器和闭环控制。
- 未采用：麦克纳姆轮。
- 未采用原因：机械和控制复杂度对当前阶段过高。

## D-002：使用ESP32与ROS2分层架构

- 状态：确认。
- ESP32负责：实时硬件执行和底层安全。
- ROS2负责：高层组织、行为、安全审查和数据流。
- 原因：即使电脑端异常，ESP32仍必须能够超时停车。

## D-003：6.0不接入OpenAI API

- 状态：确认。
- 原因：6.0重点是移动机器人、反馈、安全和ROS2工程，不扩大为云端AI项目。

## D-004：先单部件再整机

- 状态：确认。
- 顺序：机械空底盘、单电机、双电机、编码器、闭环、距离、安全、ROS2桥、行为集成。
- 原因：降低同时出现多种错误时的排查难度。
