# Atlas 6.0 Stage 4-R：最高成功率操作手册## 1. 本阶段唯一目标本阶段只验证：- ESP32 程序、串口和 GPIO 控制正常；- 两台 Hiwonder 电机本体正常；- L298N 的 A、B 两个通道正常；- 两台电机能够分别正转、反转和停止；- 两台电机能够同时短时运行；- 非法命令、动作到期和人工 `STOP` 都能停车。本阶段不接编码器、ROS 2、US-100、桌沿传感器或 AI；不落地行驶。## 2. 必须使用的硬件- ESP32 DEVKIT_C；- HW-095/L298N 模块；- 两台 Hiwonder 六线编码电机；- 带开关的四节 AA 电池盒；- 四节同品牌、同型号、同新旧程度的 AA 电池；- 电脑 USB 线；- 数字万用表；- 18/20AWG 动力线；- 杜邦信号线；- 绝缘胶带或热缩管；- 绝缘支架，使两个驱动轮完全离开桌面。旧 TB6612、2A 汽车保险丝、保险丝座和蘑菇急停不进入这一轮测试回路。## 3. 绝对停止条件出现以下任意一种情况，立即输入 `STOP`、关闭 AA 电池盒开关，再拔掉 USB：- 冒烟、火花或焦味；- 电机或 L298N 发出异常尖叫、猛烈抖动；- 电机不转但持续嗡响；- 导线、端子或 L298N 在几秒内明显发热；- 车轮、底盘或支架移动；- 电池盒、驱动板或电机极性无法确认。不要用手提着机器人测试，不要让车轮接触桌面，不要进行堵转测试。## 4. 固定接线表### 4.1 ESP32 到 L298N| ESP32 | L298N ||---|---|| GPIO13 | ENA || GPIO14 | IN1 || GPIO4 | IN2 || GPIO32 | IN3 || GPIO23 | IN4 || GPIO33 | ENB || GND | GND || 5V/VIN（USB 的 5V） | 5V 逻辑端 |### 4.2 电机与动力电源| 部件 | L298N ||---|---|| 左电机 M+ | OUT1 || 左电机 M− | OUT2 || 右电机 M+ | OUT3 || 右电机 M− | OUT4 || AA 电池盒正极 | `12V` / `VIN` / `VS` 动力输入 || AA 电池盒负极 | GND |只按电路板丝印识别端子，不按照片中的左右位置猜测。### 4.3 三个跳线- 拆掉 `ENA` 跳线，GPIO13 才能控制 A 通道 PWM；- 拆掉 `ENB` 跳线，GPIO33 才能控制 B 通道 PWM；- 本四节 AA 方案拆掉 `5V-EN` 跳线；- 拆掉 `5V-EN` 后，ESP32 的 USB 5V/VIN 给 L298N 的 `5V` 逻辑端供电；- `5V-EN` 跳线未拆时，绝对不能再把 ESP32 5V 接到 L298N 5V 端。Hiwonder 电机另外四根编码器线全部不接，并且逐根单独绝缘。只使用确认标记为 `M+` 和 `M−` 的两根线，不根据颜色猜测。## 5. 第 0 步：建立安全测试台1. 关闭 AA 电池盒开关。2. 拔掉 ESP32 USB。3. 用绝缘支架托住底盘，让左右驱动轮均离桌面至少约 2cm。4. 转动左右轮，确认轮子不碰支架、电线或桌面。5. 固定动力线，确保不会卷入轮子。6. 给两个电机贴上 `LEFT`、`RIGHT` 标签。7. 给六根电机线确认 `M+`、`M−` 和四根编码器线。8. 拍摄一张跳线、端子和全部标签都清楚的照片，作为接线前记录。只有这八项全部完成才进入下一步。## 6. 第 1 步：万用表检查 AA 电池盒1. 红表笔插 `VΩ`，黑表笔插 `COM`。2. 万用表选择直流电压档，不要选择电流档。3. 电池盒与其他设备保持断开。4. 打开电池盒开关。5. 黑表笔接电池盒负极，红表笔接正极。6. 记录电压和正负号。7. 关闭电池盒开关。四节新碱性电池通常应接近 6V；四节充满的镍氢电池通常接近 4.8–5.6V。若读数明显偏低、不断跳动或显示负号，先处理电池、电池方向或引线极性。绝对不要把万用表置于 A/mA 档后并接在电池两端，这会形成短路。## 7. 第 2 步：两台电机脱离 L298N 直接测试每台电机分别做一次，不能跳过。1. L298N 和 ESP32 均不连接。2. AA 电池盒开关保持关闭。3. 电池盒正极接该电机 `M+`，负极接 `M−`。4. 确认轮子悬空、接头牢固。5. 打开电池盒开关约 0.3 秒，立即关闭。6. 记录是否转动、方向、声音是否正常。7. 对第二台电机重复相同步骤。判断：- 两台均转：电池盒和两台电机本体基本通过；- 某一台不转：先处理该电机、M+/M−识别或连接线；- 两台都不转：先处理电池盒、电池或 M+/M−识别；- 只嗡响不转：立即断电，检查机械卡滞，不继续延长时间。本步骤不通过，不得进入 L298N 测试。## 8. 第 3 步：只连接 ESP32 和 L298N 逻辑部分此时 AA 电池盒仍保持断开。1. 拆掉 `ENA`、`ENB`、`5V-EN` 三个跳线并单独保存。2. 按固定表连接六根 GPIO 信号线和 GND。3. ESP32 `5V/VIN` 接 L298N `5V` 逻辑端。4. 不连接电机，不连接 AA 电池盒动力正极。5. 检查 ESP32 5V 没有误接到 `12V/VIN/VS` 动力端。6. 插入 ESP32 USB。7. 用万用表直流电压档测量 L298N `5V` 对 GND，应约为 5V。8. 断开 USB，完成代码上传前的接线复核。## 9. 第 4 步：上传完整程序Arduino IDE 设置：- Board：`ESP32 Dev Module`；- Port：选择 ESP32 对应端口；- Serial Monitor：`115200 baud`；- 行尾：`Newline`。操作：1. AA 电池盒开关保持关闭且动力线不接。2. 打开 `Atlas_Stage4R_L298N_Safe_Test.ino`。3. 编译并上传完整程序。4. 如果一直停在 `Connecting...`，按住 ESP32 `BOOT`，出现写入进度后松开。5. 打开串口监视器。必须看到：```textSTOPPED;REASON=BOOT_DEFAULT;ARMED=NOATLAS_STAGE4R_READY```依次输入：```textSTATUSARMLF 160 300STATUSHELLOSTATUS```在没有电机动力电源时，正确结果是：- `STATUS` 最初显示 `ARMED=NO;MOVING=NO`；- `ARM` 后显示已解锁；- `LF 160 300` 显示 `RUN`，约 300ms 后显示 `ACTION_COMPLETE`；- `HELLO` 被视为非法命令并停车、解除解锁；- 最后 `STATUS` 显示 `ARMED=NO;MOVING=NO`。本步骤不通过时，不得接 AA 电池。## 10. 第 5 步：完整无电接线与短路检查1. 关闭电池盒开关并拔掉 USB。2. 左电机 M+/M−接 OUT1/OUT2。3. 右电机暂时不接。4. 电池盒正极接 L298N `12V/VIN/VS`。5. 电池盒负极接 L298N GND。6. 确认 ESP32 GND 与该 GND 是同一点。7. 轻拉每根线，确认螺丝端子夹住的是铜线而不是绝缘皮。8. 剪去或包住外露铜丝，防止相邻端子相碰。9. 万用表置于蜂鸣/电阻档，仅在全部断电时检查：   - ESP32 GND 到 L298N GND 应导通；   - 电池正极输入到 GND 不应持续呈现接近 0Ω；   - L298N 5V 到 GND 不应持续呈现接近 0Ω。10. 完成后把万用表调回直流电压档，避免后面误用。电容充电可能导致短暂蜂鸣；若持续蜂鸣或接近 0Ω，停止并检查短路。## 11. 第 6 步：测试 A 通道和左电机严格按以下上电顺序：1. 电池盒开关关闭。2. 插入 ESP32 USB。3. 打开串口，确认 `BOOT_DEFAULT` 和 `ARMED=NO`。4. 打开 AA 电池盒开关。5. 确认电机没有自动转动；若自动转动，立即关闭电池盒。6. 输入 `ARM`。7. 输入 `LF 160 300`。8. 观察左轮是否转动，程序应在约 300ms 后自动停车。9. 输入 `LF 200 300`，仅在 160 不转且没有异味、发热、嗡响时执行。10. 输入 `LB 160 300` 测试反向；必要时再用 `LB 200 300`。11. 输入 `STOP`。12. 关闭电池盒开关。13. 拔掉 USB。一次只提高 PWM，不延长动作时间。不要超过程序限定的 220。A 通道通过标准：- `LF` 和 `LB` 都能让电机向相反方向转动；- 每次在 300ms 后自动停止；- `STOP` 后显示 `ARMED=NO`；- 无焦味、火花、异常声或快速发热。## 12. 第 7 步：交叉确认 A 通道1. 全部断电。2. 把右电机接到同一个 OUT1/OUT2。3. 重复第 11 节的 `LF`、`LB` 短时测试。若左右电机在 A 通道都能转，A 通道通过。若左电机能转而右电机不能转，问题跟随右电机或右电机线；若两台都不能转，问题集中在 A 通道、ENA、IN1/IN2、逻辑 5V、动力电源或共地。## 13. 第 8 步：测试 B 通道1. 全部断电。2. 把一台已经确认正常的电机接到 OUT3/OUT4。3. 按相同上电顺序启动。4. 输入 `ARM`。5. 输入 `RF 160 300`。6. 必要时输入 `RF 200 300`。7. 输入 `RB 160 300`。8. 必要时输入 `RB 200 300`。9. 输入 `STOP`。10. 关闭电池盒并拔掉 USB。11. 换另一台电机到 OUT3/OUT4，再重复一次。至此应完成四种组合：| 测试 | 电机 | 通道 | 正向 | 反向 | 结果 ||---|---|---|---|---|---|| A1 | 左 | A |  |  |  || A2 | 右 | A |  |  |  || B1 | 左 | B |  |  |  || B2 | 右 | B |  |  |  |## 14. 第 9 步：恢复双电机接线全部断电后：- 左电机接 OUT1/OUT2；- 右电机接 OUT3/OUT4；- 再次确认四根编码器线均未接且逐根绝缘；- 再次确认轮子悬空；- 再次确认 ENA、ENB、5V-EN 三个跳线均已拆除。按固定上电顺序启动，依次测试：```textARMF 160 300B 160 300TL 160 300TR 160 300STOP```每条动作命令之间等待串口显示 `ACTION_COMPLETE`。如果单电机都通过但双电机不转或 ESP32 重启：- 立即关闭电池盒；- 检查电池是否同型号且电量足；- 检查电池盒电压是否在双电机启动时明显下降；- 检查动力端子和 GND 是否松动；- 不要用延长运行时间的方法强行测试。## 15. 第 10 步：统一“车体前进”方向双电机都转不等于方向已经正确。机器人左右电机是镜像安装，`F` 命令下可能有一个轮子方向相反。1. 观察 `F 160 300` 时两个轮子的轮缘运动方向。2. 判断每个轮子是否都在推动机器人向车头方向前进。3. 如果左轮相反，把代码中的 `LEFT_INVERTED` 从 `false` 改为 `true`。4. 如果右轮相反，把 `RIGHT_INVERTED` 从 `false` 改为 `true`。5. 关闭电池盒，再重新上传完整程序。6. 重新执行 `F/B/TL/TR` 四项悬空测试。不要同时交换电机线又修改软件方向；一次只改变一个变量。## 16. 第 11 步：安全逻辑验收轮子仍然悬空。| 测试 | 操作 | 合格结果 ||---|---|---|| 开机默认停止 | 电池关闭，USB 启动；再打开电池 | 电机不自动转，显示 `BOOT_DEFAULT` || 未解锁保护 | 不输入 `ARM`，直接输入 `F 160 300` | 不转，显示 `NOT_ARMED` || 动作到期 | `ARM` 后输入 `F 160 500` | 最迟约 500ms 自动停止 || 非法命令 | 输入 `F 300 500` 或 `HELLO` | 停车并解除解锁 || 人工停车 | `ARM` 后输入动作，立刻输入 `STOP` | 停车并显示 `USER_STOP` || 状态反馈 | 输入 `STATUS` | 显示 armed、moving、active 和限制值 || 电池开关断电 | 短时动作中关闭电池盒开关 | 电机动力立即消失 |不要在电池开关打开时上传程序、按 ESP32 RESET/EN 或修改接线。## 17. 故障定位表| 现象 | 最可能范围 | 下一步 ||---|---|---|| 电机直连 AA 也不转 | 电池、电池盒、M+/M−、电机 | 不接 L298N，先解决本体 || 电机直连会转，两通道都不转 | 5V 逻辑供电、共地、跳线、ENA/ENB、动力输入 | 复查第 4、8、10 节 || A 通道正常，B 通道四组都失败 | ENB、IN3/IN4、OUT3/4 或 B 通道 | 复查 GPIO32/23/33 与端子 || B 通道正常，A 通道四组都失败 | ENA、IN1/IN2、OUT1/2 或 A 通道 | 复查 GPIO14/4/13 与端子 || 某一电机在 A、B 都失败 | 该电机或其线 | 重做直接测试 || PWM160 不转，PWM200 能转 | L298N 压降和启动转矩 | 记录最低可靠启动 PWM || 单电机正常，双电机失败 | AA 电池输出或线路压降 | 换同型号满电电池、紧固动力线 || ESP32 串口重启 | 5V/GND 接错、短路、接地松动或电机干扰 | 立即断电并逐层退回 || L298N 很快变热 | 电机电流过大、接线错误、机械阻力 | 停止，不继续加 PWM/时间 |## 18. Stage 4-R 最终通过标准必须同时满足：- ESP32 能稳定上传程序；- 启动后默认 `DISARMED/STOPPED`；- 两台电机直连 AA 均能转；- 两台电机分别在 A、B 通道均能正反转；- 双电机能同时短时运行；- `F/B/TL/TR` 方向正确；- 动作到期在不超过 500ms 后停车；- 非法命令停车并解除解锁；- 电池盒开关能立即切断电机动力；- 所有动力连接无明显发热；- L298N 无快速过热、异味或火花；- 全部测试均为有人看守的车轮悬空测试。通过后，本阶段仍然不能直接进行桌面边缘自主移动。落地行驶、编码器闭环和防跌落传感器属于后续阶段。
