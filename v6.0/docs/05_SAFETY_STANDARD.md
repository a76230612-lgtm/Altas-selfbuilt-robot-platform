# 05 — Atlas 6.0安全标准

## 软件强制规则

1. 上电默认停车，所有PWM输出为0，TB6612保持禁用。
2. 未收到有效ARM命令时禁止移动。
3. STOP和DISARM拥有最高优先级并立即停车。
4. 非法、缺字段、超范围或校验失败的命令不得执行。
5. 串口、心跳或运动命令超时必须停车。
6. ROS2、Python或串口桥退出必须触发停车。
7. 距离传感器无效不得解释为道路安全。
8. ESP32复位或看门狗重启后不得恢复之前的运动。
9. 安全状态恢复后必须重新ARM，不得自动继续。

## 电气规则

1. 电机不得由ESP32 GPIO、3.3V或5V引脚供电。
2. 舵机电源与底盘电机电源分开。
3. 按最终设计确认所有系统共地。
4. 接线或拔线前必须断开电机电源。
5. 第一次通电前检查正负极、额定电压、短路和裸露导线。
6. 电机驱动、电池、导线、开关、保险丝和急停规格必须确认后使用。

## 实体测试规则

1. 第一次电机测试时车轮必须悬空。
2. Atlas头部暂不安装，避免重心过高和摔落。
3. PWM从低值开始，初始不超过70/255。
4. 急停或断电开关必须触手可及。
5. 成人监督焊接、切割、第一次驱动通电和首次落地测试。
6. 每轮测试前先写验收标准，一次只改变一个变量。
7. 发现异常发热、异味、冒烟、重启或失控时立即断电。

## 当前Stage 2限制

- 禁止连接底盘电机。
- 禁止运行运动程序。
- 仅允许工程文件、文档和安全占位固件检查。
