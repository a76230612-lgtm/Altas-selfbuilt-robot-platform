# Atlas 6.0 工具与仪表操作说明标准

状态：已锁定  
锁定日期：2026-08-12  
适用对象：Eric、ChatGPT/Codex，以及所有 Atlas 6.0 实体测试步骤

## 1. 强制说明规则

以后只要操作涉及台式电源、万用表、测试线、充电器或其他带按钮/旋钮/插孔的工具，操作步骤必须明确写出：

1. 操作开始前，设备应处于通电还是断电状态。
2. 要按的按键在面板上的准确文字、颜色和位置。
3. 要转的旋钮在面板上的准确文字，以及应对准的档位或屏幕目标数值。
4. 红线、黑线分别插入或夹到哪个带文字/符号的插孔或端子。
5. 执行前后屏幕应显示什么。
6. 哪一步才能打开输出，哪一步必须保持输出关闭。
7. 出现什么显示、声音、温度、气味或动作时必须立即停止。
8. 测试结束后，应按什么顺序关闭输出、关闭主电源和拆线。

禁止只写“接好万用表”“调到电压档”“设置好电源”“打开电源”等模糊指令。

如果现有照片或说明书不足以确认某个按钮、旋钮、菜单或插孔的功能，不得凭经验猜测。必须先请 Eric 提供对应位置的近照、说明书页面或实际屏幕显示，再给出通电操作。

## 2. 工具照片索引

### 工具01：MAISHENG MN305S 台式直流电源

照片文件：`Atlas_6.0_工具01_MAISHENG_MN305S_台式直流电源_正面.jpg`

当前照片可确认的面板部件：

- 左侧旋钮：`CURRENT`，下方标有 `LOCK`。
- 中间灰色按键：`OUTPUT`，下方标有 `ON/OFF`。
- 右侧旋钮：`VOLTAGE`，下方标有 `MENU`。
- 左下红色按键/开关：主电源 `ON/OFF`。
- 中下黑色接线柱：负极 `−`。
- 右下红色接线柱：正极 `+`。
- 显示区：电压 `V`、电流 `A`、功率 `W`。

以后操作这台电源时，必须明确区分：

- 红色主电源 `ON/OFF`；
- 灰色输出 `OUTPUT ON/OFF`；
- `CURRENT/LOCK` 旋钮；
- `VOLTAGE/MENU` 旋钮。

“主电源已开”不等于“输出已开”。接线、换线和检查极性时，`OUTPUT` 必须保持关闭。

### 工具02：香蕉插头转鳄鱼夹测试线

照片文件：`Atlas_6.0_工具02_香蕉插头转鳄鱼夹测试线_红黑.jpg`

- 红色香蕉插头与红色鳄鱼夹属于正极线。
- 黑色香蕉插头与黑色鳄鱼夹属于负极线。
- 台式电源输出开启时，红黑鳄鱼夹不得接触。
- 连接或移动鳄鱼夹前，必须先关闭台式电源 `OUTPUT`。

### 工具03：DT9205A 数字万用表

照片文件：`Atlas_6.0_工具03_DT9205A_数字万用表_正面.jpg`

当前照片可确认的四个插孔：

- `20A`：大电流测量插孔；禁止用于普通电压测量。
- `mA`：毫安电流测量插孔；禁止用于普通电压测量。
- `COM`：黑表笔公共端。
- `VΩ`：电压、电阻和相关测量的红表笔端。

测量 Atlas 使用的 0–20V 直流电压时，默认要求：

- 黑表笔插入 `COM`；
- 红表笔插入 `VΩ`；
- 旋钮三角指针对准直流电压 `V⎓` 区域中的白色 `20` 档；
- 不得对准交流电压 `V~`、电流 `A`、`mA`、电阻 `Ω` 或电容 `F` 档；
- 不得把红表笔插入 `20A` 或 `mA` 插孔后跨接电源正负极测电压。

## 3. 每次工具操作的固定输出格式

以后给 Eric 的步骤必须按以下顺序写：

1. **开始状态**：主电源、OUTPUT、被测电路分别处于什么状态。
2. **插线位置**：每根线的颜色、插孔文字和目标端子。
3. **旋钮/菜单位置**：具体旋钮、档位、目标电压或目标限流值。
4. **按键动作**：按哪个按键一次，还是长按；按下后看什么显示。
5. **预期结果**：正常屏幕数值、CV/CC状态和机器人行为。
6. **立即停止条件**：异常电流、持续CC、复位、发热、异味、嗡鸣或错误动作。
7. **关机拆线顺序**：先关闭OUTPUT，再关主电源，最后拆线。

## 4. 当前安全边界

- Eric 13岁；第一次使用新电源、第一次测电流、改变带电接线、焊接或处理可能短路的裸线时，应有成年人现场监督。
- 不得用 ESP32 的 3.3V/5V 为底盘电机供电。
- 台式电源和 L298N/ESP32 的接线修改必须在 `OUTPUT` 关闭时完成。
- 万用表测电压时必须并联测量；不得在电流插孔/电流档下跨接电源正负极。
- 任何不确定的面板操作先停止，不以试错方式通电探索。
