### A1-B02

- 原因：人体/存在检测方式对背景与残留目标较敏感。
- 措施：后续改成人脸检测，并继续观察距离与光线。
- 验证：2026-07-02 的 Bug Manager 记录写明离开画面后可显示 NO PERSON。

### A1-B03

- 原因：早期文件没有按版本独立归档。
- 措施：保留累计主程序并建立源码缺口说明；不伪造原始固件。
- 验证：本归档可追溯到累计源码和 project_log.txt。
